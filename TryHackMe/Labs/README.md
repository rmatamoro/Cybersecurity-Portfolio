# 🧪 TryHackMe Labs

## Overview

This folder documents my hands-on learning and practical experience completed through the TryHackMe platform.

The purpose of these labs is to strengthen my knowledge of cybersecurity through real-world scenarios covering offensive and defensive security, system administration, networking, Windows, Linux, Active Directory, incident response, and AI security.

Each room contains my own notes, screenshots, commands used, methodology, lessons learned, and a brief report summarizing the exercise.

> **Disclaimer:** This repository is intended for educational purposes only. Sensitive information, flags, and copyrighted challenge solutions are not published where doing so would violate TryHackMe's rules. The focus is on documenting my learning process and technical growth.

## Objectives

- Develop practical cybersecurity skills
- Reinforce theoretical knowledge through hands-on labs

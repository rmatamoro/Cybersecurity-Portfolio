## Lab Report Format

Each room follows a consistent documentation format:

- **Room Overview:**
  - Investigate a compromised Windows machine using built-in Windows forensic and administrative tools to identify attacker activity and indicators of compromise (IoCs).

- **Objectives:**
  - Examine a compromised Windows host, investigate user activity, identify persistence mechanisms, analyse Windows Event Logs, inspect network and firewall configurations, and locate evidence of attacker actions.

- **Skills Learned:**
  - Windows Host Investigation, PowerShell Enumeration, Event Viewer Analysis, User Account Enumeration, Scheduled Task Analysis, Windows Firewall Investigation, Timeline Analysis, Basic Digital Forensics, Indicator of Compromise (IoC) Identification.

- **Methodology:**
  - Used PowerShell and Command Prompt to enumerate system information and user accounts. Investigated administrator group membership, analysed Windows Event Logs, inspected scheduled tasks for persistence mechanisms, reviewed firewall rules and network artefacts, examined the Hosts file for DNS manipulation, inspected system directories for attacker tools, and correlated evidence to build a timeline of the compromise.
